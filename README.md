# UNIWAY — دليل الخدمات الجامعية الذكي (نسخة Flutter)

تحويل كامل لمشروع React/TypeScript الأصلي إلى تطبيق **Flutter/Dart** أصلي، مقسّم
إلى ملفات متعددة حسب الدور والمسؤولية.

## التشغيل

```bash
flutter pub get
flutter run
```

يتطلب Flutter SDK 3.3 أو أحدث (انظر `pubspec.yaml`).

## هيكل المشروع

```
lib/
  main.dart                     نقطة البداية (MaterialApp + RTL)
  app_root.dart                 آلة التنقل بين كل الشاشات (تقابل App() الأصلية)
  theme/
    app_colors.dart             لوحة الألوان (تقابل ثابت P)
    app_icon.dart                ويدجت رسم الأيقونات عبر path_drawing
    app_icon_paths.dart         مسارات SVG للأيقونات (مستخرجة من التصميم الأصلي)
  models/
    procedure.dart               نموذج الإجراءات الجامعية + البيانات (allProcedures)
    mock_data.dart               كل البيانات التجريبية الأخرى (مقررات، تذكيرات، إلخ)
    student_request.dart         أنواع طلبات شؤون الطلاب ومتطلباتها
    floor_rooms.dart             بيانات مخطط مبنى الخرائط
  widgets/
    common.dart                   مكوّنات مشتركة (BackHeader، RowItem، الأزرار...)
    bottom_nav.dart              شريط التنقل السفلي لكل الأدوار الأربعة
  screens/
    auth/                        تسجيل الدخول والتعريف بالتطبيق
    student/                     كل شاشات الطالب (~20 شاشة)
    high_school/                 مسار تقديم طلاب الثانوية
    doctor/                      شاشات الدكتور
    student_affairs/             شاشات شؤون الطلاب
    admin/                       شاشات الإدارة
```

## ملاحظات على التحويل

- **البيانات**: جميع البيانات التجريبية (الإجراءات، المقررات، الطلبات، أنواع
  طلبات شؤون الطلاب، مخطط المبنى، الأيقونات...) استُخرجت برمجيًا من الكود
  الأصلي (وليست معاد كتابتها يدويًا)، لضمان مطابقتها الكاملة للمحتوى الأصلي.
- **الأيقونات**: نفس مسارات SVG الأصلية (من مكتبة Lucide) تُرسم في Flutter عبر
  حزمة `path_drawing`، فالشكل مطابق تمامًا للتصميم الأصلي.
- **التنقل**: `app_root.dart` يطابق منطق التنقل الأصلي بالكامل (نفس أسماء
  الشاشات، نفس شريط التبويب الذي يظهر/يختفي حسب الشاشة noTabScreens).
- **خريطة المبنى**: نسخة مبسّطة (شبكة من الغرف الملوّنة) بدل الرسم التفصيلي
  بمحرك SVG مخصص في النسخة الأصلية، لكنها تستخدم نفس بيانات الغرف والإحداثيات.
- **إدارة متطلبات الطلبات (Admin)**: نسخة للعرض والحفظ المبسّط، بدون التعديل
  الكامل (إضافة/حذف حقول) الموجود في النسخة الأصلية.
- لا يعتمد المشروع على أي حزمة واجهة خارجية غير قياسية سوى `google_fonts`
  (خط Cairo) و`path_drawing` (رسم الأيقونات).
